# Fashion MNIST DNN Classifier

This project is a learning-based implementation of a Deep Neural Network (DNN)
for classifying clothing images using the Fashion MNIST dataset.

## Overview
The model classifies 28×28 grayscale images into 10 clothing categories using
TensorFlow and Keras.

## What I Learned
- Image normalization and preprocessing
- Deep Neural Network architecture
- Difference between training, testing, and prediction
- Role of loss, optimizer, epochs, and accuracy
- Overfitting and model evaluation

## Technologies Used
- Python
- TensorFlow / Keras
- Google Colab

## Dataset
Fashion MNIST (TensorFlow built-in dataset)
